# Security and privacy

This repository is a public **portfolio showcase**, not a distribution of the private Lyra runtime.

Do not commit API keys, passwords, authentication tokens, Wi-Fi credentials, private addresses, personally identifying logs, recordings, copyrighted model weights, or proprietary third-party code.

Any future examples, screenshots, or demonstrations must be reviewed and sanitized before publication. The operational Lyra V1 and separate Lyra V2 systems remain private.
